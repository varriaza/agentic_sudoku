# CI Hooks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auto-run tests before every local commit (blocking) and on every push/PR via GitHub Actions.

**Architecture:** A committed `hooks/pre-commit` shell script enforces tests locally via `git config core.hooksPath hooks`. A `.github/workflows/test.yml` workflow runs the same tests in CI on push and PR.

**Tech Stack:** bash, pytest, GitHub Actions (ubuntu-latest, Python 3.12)

---

### Task 1: Create the pre-commit hook script

**Files:**
- Create: `hooks/pre-commit`

- [ ] **Step 1: Create the hooks directory and script**

```bash
mkdir hooks
```

Create `hooks/pre-commit` with this exact content:

```sh
#!/bin/sh
set -e
SKIP_PAYMENT=true pytest tests/ -q
```

- [ ] **Step 2: Make it executable**

```bash
chmod +x hooks/pre-commit
```

- [ ] **Step 3: Wire it up locally and verify it runs**

```bash
git config core.hooksPath hooks
SKIP_PAYMENT=true pytest tests/ -q
```

Expected output ends with: `103 passed`

- [ ] **Step 4: Verify the hook actually blocks a bad commit**

Temporarily break a test to confirm the hook fires:

```bash
# In tests/test_grading.py, change one assertion to force a failure:
# assert validate_grid_shape(None) is None   ← make it wrong temporarily
```

Then try:
```bash

git commit -m "test hook blocks"
```

Expected: commit is blocked, pytest output shows the failure. Revert the temporary change immediately after confirming.

- [ ] **Step 5: Commit the hook**

```bash
git add hooks/pre-commit
git commit -m "chore: add pre-commit hook to enforce tests on every commit"
```

### Task 2: Create the GitHub Actions workflow

**Files:**
- Create: `.github/workflows/test.yml`

- [ ] **Step 1: Create the workflow directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 2: Create `.github/workflows/test.yml`**

```yaml
name: Tests

on:
  push:
    branches: ["**"]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python 3.12
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: "pip"
          cache-dependency-path: requirements.txt

      - name: Install dependencies
        run: pip install -r requirements.txt

      - name: Run tests
        run: SKIP_PAYMENT=true pytest tests/ -v
```

- [ ] **Step 3: Validate the YAML locally**

```bash
python3 -c "import yaml; yaml.safe_load(open('.github/workflows/test.yml'))" && echo "YAML valid"
```

Expected: `YAML valid`

- [ ] **Step 4: Commit**

```bash
git add .github/workflows/test.yml
git commit -m "ci: add GitHub Actions workflow to run tests on push and PR"
```
